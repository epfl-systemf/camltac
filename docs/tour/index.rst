A tour of Camltac
=================

Welcome to the *tour of Camltac*.

In this tour, we'll go over each of the features that Camltac proposes through a series of small examples. At the end of the tour, you'll have seen how to write tactics in Camltac like in Ltac2, but also meta-programs that use extra OCaml libraries or advanced features of Rocq.
