Camltac Documentation
=====================

Camltac is an OCaml plugin for `Rocq`_ that lets you run OCaml code within Rocq scripts. Camltac makes it possible to define OCaml meta-programs and tactics, and run them in the current Rocq state without the friction and boilerplate of setting up a plugin.

.. _Rocq: https://rocq-prover.org
